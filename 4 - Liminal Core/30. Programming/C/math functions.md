##### List of all functions:
*HINT: You have to include math.h like this: `#include <math.h>` in order for these to be available*

- `abs(x)` -> absolute value (Betrag)
- `acos(x)` -> arc cosine ($cos⁻1$)
- `asin(x)` -> arc sine ($sin⁻1$)
- `atan(x)` -> arc tangent
- `cbrt(x)` -> cube root (Quadratwurzel)
- `cos(x)` -> cosine
- `sin(x)` -> sine
- `tan(x)` -> tangent
