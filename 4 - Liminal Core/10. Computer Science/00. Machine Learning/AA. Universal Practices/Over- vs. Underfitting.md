##### Solving misfitting:
*Overfitting:*
- If you can, get more training examples
- If you have lots of features and insufficient data, drop some of the features
- reduce size of parameters using [[regularization]]
*Underfitting:*







##### Underfitting:
If a model does not fit your training set well, it is **underfit** (also referred to as having **bias**).
Example: 
![[underfit.png]]

##### Overfitting:
If a model matches the training set pretty much exactly, it is **overfit** - also called **high variance** - its predictions are perfect for the training
set, but new values are not handled well.
Example:
![[overfit.png]]

##### Generalized:
In practice, a model should always be generalized, meaning it has to strike a good balance between over- and underfitting.
