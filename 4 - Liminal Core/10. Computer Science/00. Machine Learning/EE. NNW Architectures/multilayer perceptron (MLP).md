### General:
A multilayer perceptron receives a 1D array as input (or at least treats it like one).
Furthermore, all neutrons from one layer are connected to all neutrons from the second layer.
It treats all input features equally, meaning it completely ignores their position in the original data.
In the context of images, this means it completely ignores the position of all pixels, treating them all equally.
