### General:
An opto-electric hybrid neural network essentially combines an [[optical neural network (ONN)]] with any other ML architecture.
This draws the best of both worlds, with the optical system performing linear operations such as matrix multiplications, because this is what
it naturally does in a very energy-efficient way, while the electric system handles gradient computation for [[back propagation]], storing weights
and updating them, as well as nonlinear activations (see [[logistic regression]]) and encoding/decoding into and from [[electromagnetic waves]] (often light).  
It is not an architecture, but a physical way to implement different architectures.
