##### General:
While a normal derivative is sufficient for a function with only one variable, we need 
more complex systems to represent the slope of a function while looking at only one variable
if we have multiple. This is the so-called partial derivative.
Notation:
$$\frac{\delta F}{\delta x}$$
*Here: "Derivative of F with respect to x."*

Put simply, this is the derivative for one point in the direction of x. It shows what effect a tiny change in x
will have on the result F.
