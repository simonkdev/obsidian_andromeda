### General:
Complex values are a number system that aims to solve equations like this: $x² = -1$. The solution is an imaginary number called $i$. 
In order to solve complex-valued equations, you can insert $i² = -1$ and the reverse at any point.
A complex value or a complex number is written as the sum $a + i*b$, where $a$ is called the real part and $b$ is called the imaginary part.
